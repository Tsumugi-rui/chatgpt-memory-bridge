# ChatGPT Memory Bridge v0.3.1 · 图形版

## 最快开始

双击交付目录顶层的 **双击启动图形版.lnk**。也可以在项目根目录运行：

```powershell
.\.venv\Scripts\python -m memory_bridge gui
```

这是原生 Tk 图形窗口，不需要浏览器或 Streamlit。当前电脑已具备 Python、Tk 和运行依赖。桌面快捷方式使用本机项目的虚拟环境，因此需要保留原项目目录；不是适用于其他电脑的免安装 EXE。换电脑可从“当前版本”的源码包安装依赖后运行 gui 命令。

## 四个页面

尚未拿到官方 ZIP 时，点击首页的 **官方导出助手**。它提供 ChatGPT、官方隐私门户和操作说明入口，并可在下载完成后选择 ZIP。按钮只打开官方网页，不提交申请、不读取邮件、不自动下载；登录、验证及确认申请在官方网页中进行。导出准备时间与通知由 OpenAI 决定，参见[官方说明](https://help.openai.com/en/articles/7260999-exporting-your-chatgpt-history-and-data)。

1. **导入与迁移**：选择官方 ZIP，给账号起一个固定标识，选择结果父文件夹，点击“一键迁移”。程序依次归档、解析、提取全部历史记忆、全量导出和校验；任务记录保留结果路径。也可以只导入。
2. **搜索聊天**：按消息关键词或对话标题查找，选择消息看正文与来源，查看完整对话的所有原始版本和分支。本次最多显示500条消息。
3. **记忆管理**：提取、筛选、确认、修改、标记过时、查看历史与回滚。软删除会确认，原始证据不会删。未审核内容仍可全量导出。
4. **备份与恢复**：导出当前库、校验资料库或已有迁移包、恢复到新目录。恢复成功会切换到新库；默认原库位置与 CLI 的 data/ 一致。

耗时任务在后台线程运行，窗口保留进度状态。进度显示当前处理阶段与已处理数量，不估算虚假的完成百分比。任务执行期间禁用操作按钮，等任务结束再关闭窗口。导入为 partial/rejected 会显式提示，校验通过只表示文件完整性，不等于输入已全部解析。

每次导出自动使用日期、时间和随机后缀建立新目录，不覆盖旧包。默认结果放在桌面本项目输出目录的 **迁移结果/**；可在界面改为其他位置。快捷方式对应的资料库仍在原项目 data/，不会混入程序发布包。

## 整理后的目录

```
outputs/
  双击启动图形版.lnk
  开始使用.md
  当前版本/
    使用说明.md
    验证报告.md
    ChatGPT-Memory-Bridge-v0.3.1-source.zip
    app/                          图形版运行文件
  历史版本/
    v0.1/                         原有源码、示例、报告
    v0.2/                         原有源码、示例、报告
  迁移结果/                       此后生成的个人迁移包
```

只移动本项目已知的旧交付到历史版本；不删除旧包，也不动用户额外放入的文件。项目输出和桌面副本使用相同结构，后续更新沿用同一桌面项目目录。

## 数据覆盖

继续使用 v0.2 的全量模式：原始 ZIP、全部可读成员、分支、对话版本、全部记忆状态、证据和 SQLite 快照均保留。附件匹配列出匹配/歧义/缺失；未出现的外部 SOUL/IDENTITY 文件不会自动收集。图形版没有新增在线处理，不写回 ChatGPT 官方聊天侧边栏或原生记忆。

真实官方导出与实际 Open WebUI 导入仍待验证。规则提取不是 LLM。使用方法与完整性范围也可参考 docs/personal-mode.md；该文件记载 v0.2 的 CLI 功能。开源参考在 docs/references.md。
