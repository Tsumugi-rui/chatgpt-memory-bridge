# MVP 阶段验收

## v0.2 个人全量版（2026-10-28 交付整理）

根据用户“自用，尽可能无损迁移”的要求，默认改为不过滤敏感候选、携带全部记忆状态和历史，取消固定导入容量上限。新增全成员逐字节导出（含重复/特殊路径）、附件引用匹配、账号资料定位、逐对话全分支阅读文件、平台 JSON 分片、一致数据库快照与完整 restore。记忆提取遍历全部历史版本，证据 ID 固定到原版本。

56项测试通过，包含数据库所有表的恢复前后逐行比对及恢复后增量导入。当前说明以 README.md / docs/personal-mode.md 为准；以下阶段记录描述 v0.1 的历史默认值。Open WebUI 尚未实测，真实官方数据兼容性和大文件压力测试仍待验证。

## 阶段1：环境、目录和模型

已确认 Windows PowerShell、Python 3.12.10、SQLite 3.49.1 + FTS5。项目原目录无代码。建立 src 布局、pyproject、CLI 入口和 SQLite 数据模型，设计记录在 architecture.md。依赖安装在项目 .venv 内。

未解决：官方导出没有在本项目内获得真实格式样本。后续：用合成数据先约束格式兼容与安全行为，再接入本机真实数据验证。

## 阶段2：ZIP 与原始数据归档

已实现流式复制、SHA-256 内容寻址、原始字节独立保存、ZIP 路径/重复成员/符号链接/压缩比/展开大小限制和临时清理。阶段测试：13 passed。复核中补充中央目录分配前检查、ZIP64、CRC 故障和严格同哈希修复。

未解决：HTML 仅保留，不重建消息；远端附件无法保证在导出中存在。后续：生成成员清单并明确标记未解析、未验证引用。

## 阶段3：解析、检索与增量

已实现多种 JSON 包装、mapping/messages、分支父子、未知字段和不可变原始版本。支持 FTS5 中日韩检索、时间/标题/ID 条件、幂等导入和缺失记录保留。阶段累计测试：24 passed。

未解决：缺失稳定 ID 时只能派生 ID，修改匹配不可靠；每个对话仍整体驻留内存。后续：保守规则记忆和人工审核。

## 阶段4：记忆与版本管理

已实现用户消息的明确陈述规则、默认敏感排除、疑似注入跳过、候选指纹幂等、固定消息版本证据、人工审核、内容修改后撤销确认、冲突标记、精确重复合并、软删除、历史和回滚。阶段累计测试：28 passed；后续补充人工编辑后不重复产生原候选的回归测试。

未解决：无法识别所有敏感数据、自然语言事实和语义矛盾；没有 LLM 自动提取。后续：将确认的内容写入上下文包，同时保留原始归档。

## 阶段5：迁移包、验证与加密

所需的10种迁移文件均生成，另有清单、导入报告、记忆历史及独立原始 ZIP。默认只导出已确认有效记忆，原始聊天不因过滤记忆而删除。manifest 最后写入，现有目标不覆盖。按原始字节、索引、附件、上下文和账号状态分层报告。可选流式 AES-256-GCM+scrypt 加密备份，密码只通过交互输入。阶段累计测试：35 passed。

未解决：manifest 无签名，不能证明来源真实性；普通本地库与迁移目录仍为明文。后续：错误路径、篡改和端到端安装验证。

## 阶段6：自动测试与合成演示

覆盖路径穿越、压缩炸弹上限、重复成员、ZIP64、中央目录限制、CRC 错误、多结构 JSON、缺失字段、中日文本、分支、重复/增量导入、旧中断重试、记忆冲突、版本证据、审核回滚、编辑后幂等、迁移包篡改/缺失文件、损坏数据恢复、临时清理和加密认证。

已验证 `pip install -e '.[test,crypto]'`、实际 console-script 入口和 `pip check`。合成演示运行两次导入、提取、冲突处理与人工确认，迁移包14个文件的校验通过。全部测试结果见 outputs/validation.md。

未解决：尚未使用真实官方 ZIP，也未进行多 GiB 文件或 Python 3.11 环境压力测试。不能宣称所有官方格式都兼容。

## 阶段7：后续按需扩展

首版 CLI 已形成闭环。Streamlit UI、实际 Claude/DeepSeek 适配器、在线/本地 LLM、语义主题索引、附件关联与更细粒度流式解析均未实现。优先下一步是对用户本机的真实导出做只读兼容性验证，而不是扩大自动提取范围。
